# 🚀 Звёздная экспедиция — AR-квест

Корабль «Заря-7» потерял 4 навигационных кристалла. Капитан (ребёнок 6–10 лет) с планшетом ищет спрятанные метки станций, сканирует их камерой — над меткой появляется планета в дополненной реальности — и выполняет задания. За каждую станцию — кристалл с буквой. На космодроме из букв складывается слово запуска, ракета взлетает, капитан получает удостоверение космонавта.

## Механика
| # | Станция | AR над меткой | Задание | Награда |
|---|---|---|---|---|
| 1 | 🌙 Луна | Луна с кратерами, спутник на орбите | Вопрос: кто первым полетел в космос | С |
| 2 | 🔴 Марс | Марс, марсоход, **табло с кодом** | Ввести код — он виден **только через планшет** | К |
| 3 | 🪐 Сатурн | Сатурн с кольцами и спутником | Нажать планеты по порядку от Солнца | П |
| 4 | ☄️ Пояс астероидов | Астероиды и кристаллы на орбитах | Мини-игра: поймать 10 кристаллов поверх камеры | У |
| 5 | 🚀 Космодром | Ракета на стартовом столе | Сложить из кристаллов слово **ПУСК**, зажать кнопку → отсчёт, ракета взлетает | Удостоверение |

Как выглядит AR: на метке открывается круглый **портал в космос** со звёздами и туманностью, над ним — планета с процедурной текстурой (кратеры Луны, полярные шапки Марса, полосы и кольца Сатурна), вокруг — звёздная пыль. На Марсе марсоход едет по планете, а код светится на голограмме, наклонённой к зрителю. Поверх камеры — «стекло шлема» и индикатор «● КАМЕРА».

Вокруг механики:
- **Сканирование.** Метку нужно удержать в кадре 1,4 с — вокруг прицела заполняется кольцо. Потеряли метку — сканирование сбрасывается.
- **Порядок станций.** Если навели не на ту метку, квест подскажет, какую искать сейчас.
- **Бортовой компьютер** печатает брифинг и озвучивает задания голосом браузера (если в системе есть русский голос). Звуки синтезируются в браузере, файлов нет. Кнопка 🔊 выключает звук.
- **Космофакт** после каждой станции.
- **Удостоверение космонавта** в финале: имя, номер, время миссии, дата.

## Как запустить
1. Нужен HTTPS (иначе браузер не даст камеру) — GitHub Pages или Netlify Drop.
2. Взрослый открывает `print.html`: инструкция + метки. Печатает, вырезает, прячет.
3. Ребёнок открывает `index.html` на планшете, вводит имя (или `index.html?name=Маша`).

`index.html?demo` — пройти без камеры: появится кнопка «Симулировать метку», код Марса покажется подсказкой.

## Файлы
| Файл | Что это |
|---|---|
| `index.html` | AR-сцены станций (A-Frame + AR.js) и интерфейс |
| `ar.js` | AR-компоненты: процедурные текстуры планет, портал в космос на метке, звёзды, свечение, голограмма с кодом |
| `icons.js` | Рисованные SVG-иконки (планеты, ракета, звук, камера) |
| `data/camera_para.dat` | Параметры камеры для AR.js — лежат рядом, чтобы не зависеть от чужого сервера |
| `quest.js` | Сюжет, станции, задания, ответы, факты — править тексты здесь |
| `game.js` | Логика: сканирование, 5 типов заданий, награды, запуск |
| `fx.js` | Звёздное небо, звуки, голос, салют |
| `style.css` | Оформление |
| `print.html` | Инструкция для взрослого и метки для печати |
| `markers/` | Метки: `.patt` для распознавания, `.svg` для печати. Генерирует `node tools/gen-markers.mjs` |

Код для табло Марса берётся из `quest.js` (`task.code`) — меняется в одном месте.
