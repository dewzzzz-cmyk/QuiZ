# MVP: «Сокровище капитана Флинта»

Пиратский AR-квест для детского праздника: 3 сцены, AR по распечатанным маркерам, работает в браузере телефона без установки приложения.

## Как играть
1. Откройте `markers.html`, распечатайте маркеры и спрячьте их.
2. Откройте `index.html` на телефоне (нужен HTTPS — камера без него не включится).
   Имя именинника можно передать в ссылке: `index.html?name=Маша`.
3. Находите маркеры по порядку, наводите камеру — появляется 3D-объект и загадка. После третьей загадки сундук открывается.

Пройти квест без камеры и распечатки: `index.html?demo` — появится кнопка «Симулировать маркер».

## Свой квест: `builder.html`
Форма: имя именинника, название, вступление, по загадке на каждую сцену (2–4 варианта ответа), текст финала.
Кнопка «Собрать ссылку» даёт ссылку вида `index.html?q=…` — весь квест зашифрован в ней, сервер не нужен.
- Черновик сохраняется в браузере.
- Открыть готовый квест для правки: заменить в ссылке `index.html` на `builder.html`.
- Сцены и маркеры пока одни и те же (карта, компас, сундук) — меняются только тексты.

## Файлы
| Файл | Что это |
|---|---|
| `index.html` | Игра: сцены A-Frame + AR.js, интерфейс |
| `quest.js` | Квест по умолчанию: подсказки, загадки, ответы, финал |
| `game.js` | Логика: порядок сцен, проверка ответов |
| `builder.html`, `builder.js`, `builder.css` | Сборщик своего квеста |
| `quest-link.js` | Упаковка квеста в ссылку и проверка его содержимого |
| `markers.html` | Страница для печати маркеров |
| `markers/` | Маркеры: `.patt` для распознавания, `.svg` для печати |
| `../tools/gen-markers.mjs` | Генератор маркеров всех квестов: `node tools/gen-markers.mjs` из корня репозитория |

## Где разместить
Нужна страница с HTTPS. Варианты:
- **GitHub Pages** — для приватного репозитория нужен платный тариф GitHub; для публичного бесплатно.
- **Netlify Drop** (app.netlify.com/drop) — перетащить папку `mvp`, получить ссылку.
- **Vercel** — подключить репозиторий, корневая папка `mvp`.

## Ограничения
- Проверена логика квеста (demo-режим). Распознавание маркеров нужно проверить на реальном телефоне.
- Маркеры сделаны своим генератором по формату AR.js. Если какой-то не распознаётся, пересоздайте его в официальном генераторе AR.js Marker Training и замените файлы в `markers/`.
