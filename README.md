# QuestAR

Конструктор AR-квестов: основная сцена на ТВ, телефон — AR-инструмент для поиска.
Квест собирается с помощью ИИ из одной идеи («квест про пиратов для детей 8–12 лет»).

Идея из чата «WEB AR квесты через ТВ и телефон» (9 декабря 2025).

## Как играется: ТВ + телефон

- **ТВ** показывает основную сцену с персонажем. Пример: комната замка, NPC говорит «Найди три магических кристалла!».
- **Телефон** работает как AR-инструмент: игрок ищет объекты и решает загадки через камеру.

## Конструктор квестов

- **Слева — AI-помощник.** Пишешь идею («квест про пиратов для детей 8–12 лет»), жмёшь «Сгенерировать».
- **Справа — визуальный редактор.** Цепочка сцен до финала; кнопки «добавить AR-объект», «добавить загадку», «добавить NPC».
- **Внизу — библиотека ассетов** (пират, карта, сокровище, попугай); новые ассеты генерирует ИИ.
- **Три режима создания:** полностью ИИ · по шаблонам (детектив, приключение, обучение) · вручную.

## QuestAR Studio v2.0 — «автономный ИИ-коллектив»

- Человек задаёт только идею, дальше работает цепочка агентов:
  архитектор → профильные агенты → QA → «судья», который одобряет публикацию. Между агентами есть обратная связь.
- Аналитика сама улучшает квесты (например, упрощает слишком сложную загадку).
- Кэширование ассетов и промптов; запасные варианты при недоступности ИИ-сервиса
  (вместо голоса — субтитры, при перегрузке основной модели — меньшая модель).
- Целевые метрики: ~95% автономности, квест создаётся примерно за 12 минут.

## Дорожная карта

| Этап | Что входит |
|---|---|
| **1. MVP** | 3 сцены, WebAR по картинкам-маркерам в браузере телефона. Без ТВ и озвучки. |
| **2. Конструктор** | Редактор сцен, библиотека ассетов, генерация квеста ИИ, шаблоны. |
| **3. ТВ + телефон** | Сцена и NPC на ТВ, телефоны подключаются по QR-коду, синхронизация. |
| **4. Studio v2.0** | Цепочка агентов, QA и «судья», аналитика, запасные варианты. |
